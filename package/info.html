Holo Retro-Go

复古游戏模拟器

支持 NES、GB/GBC、MD/Genesis、SMS、GG、ColecoVision、PCE 等核心。

NES / GB 可满速运行
MD / Genesis 50 模拟 / 28 渲染帧
音频 开启状态稳定

ROM 游戏放置位置

  • /sd/roms/<system>/
  • 例如：NES 放 /sd/roms/nes，MD 放 /sd/roms/md。
  • 常用目录：nes、gb、gbc、md、sms、gg、col、pce。

应用信息 版本与大小

版本号 1.2
安装包大小 4.87 MB

手柄 Xbox / ShanWan Q36 映射

方向D-pad 或左摇杆
A / B / X / Y普通核心按同名键；MD 中 A=A、X=B、B=C。
L / RXbox 为 LB/RB，Q36 为 L1/R1；MD 中 RB 也可作为 B。
RT / R2MD B 快捷键
STARTXbox Menu/Start，Q36 START
SELECTXbox Back/Select，Q36 SELECT
菜单Xbox View，Q36 MENU/Option
退出Xbox/Guide 或 HOME 返回系统
